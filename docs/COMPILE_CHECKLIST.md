# TwinPulse Hedge EA - Compile checklist

This sandbox has no MetaEditor, so the sources were **not** compiled here.
Every file was reviewed line by line against this checklist and against the
MQL5 documentation. The owner must run the checklist on his own Windows PC
before he uses the EA.

## How to use this list

1. Open each file in the list, read the line, confirm the answer.
2. Compile the three sources, the log must show **0 errors**.
3. Run `TwinPulseSelfTest`, every line must print **PASS**.
4. Tick the boxes in the table at the end of this document.

## Result of the static review in this sandbox

* 145 functions, 469 call sites, no duplicated identifier, no use before the
  definition, no unbalanced bracket, no MQL4 call. This was checked with a
  temporary script that is **not** part of the repository (the repository may
  only contain `tools/build_single.py`).
* The `dist\TwinPulse_single.mq5` was generated and checked (no project
  include, no `#pragma once`).
* **Wine attempt:** MetaEditor 64 was installed under Wine in this sandbox
  (the MT5 setup was downloaded and installed), but `MetaEditor64.exe` aborts
  under Wine with a hard error before it can compile, also for a trivial
  one line test file. The compilation was therefore **skipped**, exactly as the
  specification allows when the compiler cannot be used in the build
  environment.
* **Not** verified here: the compilation itself, the behaviour in the Strategy
  Tester and the behaviour on a live account. These need the owner's Windows PC.
