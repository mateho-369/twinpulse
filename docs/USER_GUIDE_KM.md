## 1. អ្វីគឺ TwinPulse Hedge EA

TwinPulse គឺជា Expert Advisor (EA) សម្រាប់ MetaTrader 5 ដែលធ្វើតាមគំនិតរបស់អ្នក៖

* បើក **វគ្គ (cycle) មួយ** មាន **២ ប្រព័ន្ធ BUY + ២ ប្រព័ន្ធ SELL** នៅលើ XAUUSDm ដោយប្រើ magic តែមួយ។
* ខាងដែលចូលដល់គោលដៅ (ចំណេញតូច) ត្រូវបាន **បិទ** ហើយប្រាក់ចំណេញត្រូវបាន **រក្សាទុក (bank)** ក្នុងគណនី។
* ខាងដែលនៅស្មានការបាត់ត្រូវ នៅតែដែលបានបើកទៅ រហូតដល់វាត្រឡប់មកដល់តំណែងប្រហែល (break-even) ទៀតវិញ ខាងដែលបានបិទ ត្រូវបាន **បើកម្តងទៀត** ដើម្បីឲ្យមានភាពស្មើគ្នាវិញ (២ BUY + ២ SELL) ដដែល។
* ច្បាស់នៅ BUY និង SELL ដោយប្រើវិធានដូចគ្នា។

EA មាន 3 របៀបធ្វើការ៖

| របៀប | ន័យ |
|---|---|
| **FULL** (លំនាំដោយល្នាក់) | មានគ្រប់ទាំង៖ ការរកឃើញស្ថានភាពទីផ្កាល់ (regime) ចំណេញធានា (bank) ការការពារគ្រោះ (brakes) សម័យ ពិភាក្សា និងពេល។ |
| **PURE_IDEA** | តែគំនិតរបស់អ្នកតែមួយ៖ បើក ៤ ប្រព័ន្ធ បិទខាងដែលចំណេញ ហើយបើកម្តងទៀតពេលខាងស្មានបាត់ត្រូវត្រឡប់មកដល់ break-even។ គ្មាន regime គ្មាន bank។ |
| **ONE_SIDE** | ប្រតិបត្តិតែខាងដែលទាប់តាមនិន្ទុស្មាន H1 (គ្មាន hedge)។ |

## 2. អ្វីត្រូវដឹងមុនពេលប្រើ

1. **គណនីត្រូវជា HEDGING** (មិនមែន NETTING)។ បើកក្នុង MetaTrader៖ `Tools → Options → Accounts` ហើយមើលថា **Allow hedging** ដែលបានភ្ជាស់។ បើកមិនជា HEDGING ទេ EA នឹងមិនបញ្ជាទិញអ្វីទាំងអស់ ហើយបង្ហាញផ្ទាំងក្រហមពណ៌ជាមួយមានមូលដ្ឋានថាមិនអាចបញ្ជាទិញបានទេ។
2. **នៅកុំបើកលើគណនី REAL** ពេលមិនទាន់ត្រូវ។ លំនាំកុំបើកដល់វិញ `AllowLive=true` រហូតដល់អ្នកបានប្រាកដតាមការណែនាំក្នុងឯកសារទី ៦។
3. ប្រើតែ **XAUUSDm** និងក្រេត **M5**។
4. ត្រូវមានប្រព័ន្ធ **Stop Loss ជាប់មុខម្លោះ (broker-side)** គ្រប់រាល់ប្រព័ន្ធដែល EA បើក (ដើម្បីការពារអ្នក បើកទីតាងក្រោយក៏នៅតែបាន)។

## 3. ការដំឡើង (ជាមួយ Windows)

ក្រ៞សូមមើលឯកសារ **WINDOWS_RUNBOOK_KM.md** ដែលមានពាក្យគ្រប់យ៉ាងមួយយ៉ាងដោយភ្នៀង។

សេចក្តីសង្ខេប៖

1. ចម្លង `MQL5\` ទាំងអស់ ទៅក្នុង **File → Open Data Folder** របស់ terminal។
2. ចម្លង `MQL5\Profiles\Tester\*.set` ទៅ `MQL5\Profiles\Tester\` ក្នុងថតិចដែលរបស់ terminal (ទាំងការដំឡើង ទាំងថតិចទិន្នន័យ)។
3. Compile ដោយប្រើ `metaeditor64.exe /compile:... /log` — ត្រូវមាន **0 error**។
4. ដំឡើង `TwinPulseSelfTest` លើងនៃតាងក្នុងត្រាំងសាកល្បង (chart) ណាយ — ត្រូវមានតែ **PASS**។
5. ដំឡើង `TwinPulseNewsExport` ម្តងនៅតាងក្នុងគណនីផ្អែក (live) — បង្កើតឯកសារ `Common\Files\TwinPulse_news.csv`។

## 4. ការប្រើ EA លើគណនី Demo

1. បើក chart របស់ **XAUUSDm** នៅរយៈពេល **M5**។
2. អូស `Navigator → Expert Advisors` → ដំឡើង **TwinPulse** ទៅលើ chart។
3. ក្នុងផ្ទាំងកំណត់ ជ្រើសរើស:
   * `Mode` = **FULL**
   * `AllowLive` = **false**
   * `BaseLot` = **0.01**
   * `LotMultiplier` = **1.0** (កុំប្ដើរបន្ថែម)
   * `IUnderstandMartingaleRisk` = **false**
   * `RiskMode` = **FIXED**
4. ចុច **OK** ហើយបើក **Algo Trading** នៅប៊ីតាងខាងលើ។
5. ត្រូវប្រាកដថាផ្ទាំងក្រហមពណ៌ (panel) បង្ហាញនៅជង់ក្រោមខាងស្មើរបស់តាង។

## 6. ហេតុផលដែលត្រូវប្រុងប្រយ័ត្ន (តាមការស្រាវជ្រាវរបស់អ្នក)

* **ទិសដៅចេញខ្លាំង (trend)** គឺជាគ្រាយធំបំផុត ព្រោះប្រព័ន្ធ hedge បំពានការទូទាត់តែពេលវិញ ហើយខាងដែលទាប់តាមទិស នឹងបន្ថែមចំណេញជាបន្ត រហូតដល់បាត់ត្រូវផ្អាកក្នុងសម័យឆ្លងមក។ របៀប FULL ដែលប្រើ regime បានការពារនេះ។
* **ពេលដែលការបង្ហាញប្រាកដ (spread) ធំ** ជាពិសេសម៉ោង ២២:០០–២៣:០០ តាមម៉ោង UTC នៅ XAUUSDm អាចធ្វើឲ្យគោលដៅ និងការបិទទាំងអស់មិនច្បាស់។ EA រារាំងបញ្ឈប់ដោយខ្លួនឯងនៅកម្រិត ២ ដងនៃតម្លៃចម្ងាយមធ្យម និងកម្រិតអតិបរមាដែលខុសទៅ។
* **សម័យប្តាហ៍ (ស្លែក)** អាចបង្ហាញចន្លោះធំ ដែលធ្វើឲ្យប្រព័ន្ធចំណេញធ្វើឲ្យបិទឆាប់។ នោះគឺជាមូលហេតុផលដែល EA បិទទាំងអស់ម៉ោង ២០:៤៥ ថ្ងៃសុក្រ។
* **Swap (ការបង្ហាញថ្លៃការជួល)** អាចចំណេញទៅលើប្រព័ន្ធ SELL រហូតដល់ពាក្យប្រោះ ហើយបញ្ជាទិញប្រព័ន្ធក្នុងវគ្គទាំងអស់ចំនួនមួយធ្វើឲ្យបានការបង្ហាញថ្លៃមួយធ្វើ។ ត្រូវពិនិត្យតម្លៃ swap ក្នុងប្រព័ន្ធរបស់ broker ជាមួយការរកឃើញទីតាង swap នៅក្នុងប្រព័ន្ធ។
* **ព័ត៌មាដែលធំ** អាចធ្វើឲ្យតម្លៃរំលងឆ្លង ដូច្នេះការបិទទាំងអស់នៅក្នុងពេលត្រូវបាន។ នៅក្នុងការសាកល្បង (tester) ត្រូវរប្បង `TwinPulseNewsExport` ម្តងនៅតាង live ជាមុនសាកល្បង។
